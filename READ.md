# Alumni Tracking System

This project is an Alumni Tracking System developed for the Web Programming course (YBSB3001) at Istanbul University.

## Tech Stack Decisions

* **Language:** Python
  * *Why:* Easy to learn and fast to write.
  * *Weakness:* Slower than C++ or Go.
* **Database:** PostgreSQL
  * *Why:* Reliable and widely used for relational data.
  * *Weakness:* Can be harder to scale.
* **AI Assistant Used:** ChatGPT
